A value is the text after the label (colon optional), up to the next label or a wide column gap. If nothing follows the label on its line, the value is read from the line below. Name of Work and Name of Agency also pick up a wrapped second line that starts at the same position. Dates are read as day-month-year (15-Sep-26, 15/09/2026, 15.09.2026, 15 September 2026, September 15, 2026). For Amount, the tool finds the Gross Value column heading and takes the number on the Net Payable Amount row under it. If there is no Gross Value heading, it uses the largest number on that row (Gross = Basic + Tax) and flags the row for a check. A page with none of PROJECT, PO ref or Name of Agency is treated as a continuation of the previous page.
